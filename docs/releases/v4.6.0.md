# Stage_Manager_Lai v4.6.0

## 新功能

- 可选 AI 额度卡片：新安装及旧版升级默认关闭。已有试用用户保留选择，可在设置中启用 Codex、DeepSeek、Kimi。
- 改进额度详情面板的文字、布局与显示层级。
- 每个应用独立展开、FIXED 与分页，固定一个应用不再阻止其他应用展开。
- 设置和托盘新增手动“检查更新”；用户确认后下载并校验，原路径升级，失败回退。
- 每个新版首次启动显示一次中英文更新介绍，全屏时延后，不自动开启新功能。

## 更新方式

旧版本没有检查更新功能，需要先手动下载安装一次本版本。之后可在设置或托盘中手动检查更新。不后台检查、不自动下载，不需要 GitHub 登录。

升级保留原 EXE 的路径和文件名，现有快捷方式不变；实际版本请以程序内版本信息为准。校验文件缺失或失败、权限不足等情况停止升级并提供发布页手动下载入口。

API 密钥仅由当前 Windows 用户加密保存，不包含在分享 EXE 中。AI 余额不是免费聊天次数。SHA-256 提供下载完整性检查，不等同于代码签名。

## 发布门槛

本地实现及自动回归不代表长期稳定性验收已完成。正式资产由标签 CI 构建、生成 SHA-256 与构建证明。
