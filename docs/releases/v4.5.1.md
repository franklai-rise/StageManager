# Stage_Manager_Lai v4.5.1

Fix launcher cards occasionally showing a generic icon for Chrome, Edge or other apps.

- Initialize COM on background icon threads before invoking Shell icon APIs.
- Read executable icons directly; retain custom shortcut and packaged-app icons.
- Retry transient failures three times without caching a generic icon as success.
- Failed cards can retry when hovered after a ten-second cooldown.
- Cancel retries and dispose late images when a card closes.
- Synchronize the late-image regression test before inspecting disposed GDI+ images.
- Keep a bounded local failure log without full paths or document titles.

All existing layout, Focus, FIXED, activation and shortcut behavior is retained.
This CI-built EXE is initially a draft pending local validation under the release policy.

Verify SHA256SUMS.txt and build-info.json, then:

```powershell
gh attestation verify Stage_Manager_Lai_v4.5.1.exe --repo franklai-rise/StageManager
```
