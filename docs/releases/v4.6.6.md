# Stage_Manager_Lai v4.6.6 · 顶部新形态

本次正式更新将此前的本机试用改进统一带入公开版本。卡片栏支持顶部、底部、左侧和右侧停靠；顶部／底部采用全新的三行组合卡片，适合竖屏和横向工作流。

## 主要更新

- **顶部／底部三行卡片**：同一应用每卡最多三个窗口，1 个占满、2 个均分、3 个三等分；超出后自动生成相邻续卡，标注应用和页序。窗口顺序保持稳定，每行直接切换或最小化对应窗口。
- **工具组合**：快捷方式每三项组合成一卡；显示／恢复桌面、桌面图标和收起组合显示。图钉固定、AI 额度及隐藏图标卡保持各自用途。
- **边缘自动滑动**：横栏支持滚轮，鼠标靠近横栏左右边缘可自动滑动，越靠边越快；离开、点击或打开弹窗时停止。
- **完整预览**：顶部／底部截图与显示都保留横向、竖向窗口的完整比例，浅灰留白；继续使用低频静态截图和独立截图进程。
- **统一外观**：大卡片统一尺寸、4° 倾斜、合理间隔。应用名和窗口标题采用透明底深灰文字；顶部收起箭头向上，底部向下。
- **四边 Focus**：按当前停靠方向预留工作区，独占全屏时仍可从相应边缘唤出。左右模式保留原有多窗口展开和独立 FIX/FIXED 状态。
- **Antigravity**：AI 额度卡新增独立 Antigravity 行、图标和本机额度读取；详情页调整模型列表展示与图标对齐。AI 总开关仍默认关闭，已有设置保留。
- **边界修复**：清理关闭窗口的悬停引用；切换到横栏时释放待处理截图，避免影响后续预览刷新。

## 下载与升级

下载 `Stage_Manager_Lai_v4.6.6.exe`：Windows 10 版本 2004 或更新的 x64 系统，自包含单文件，无需另装 .NET。

现有 v4.6.x 可在设置或托盘中手动检查更新，确认后升级。旧版本没有更新入口时，退出旧实例，再运行新 EXE。设置及 API 密钥不包含在分享文件中。

仅需主程序时下载 EXE。Gemini 网页订阅桥接为可选独立组件，需要时再下载 `Stage_Manager_Lai_Gemini_Companion_v4.6.6.zip` 并按其中的 `INSTALL.txt` 配置。

正式文件由本标签 GitHub Actions 构建，附带 `SHA256SUMS.txt`、`build-info.json` 与 GitHub 构建证明。SHA-256 用于完整性校验，当前 EXE 未进行发布者代码签名。

## 使用提示

从系统托盘打开设置，选择顶部或底部。横向模式直接显示各窗口行，无需悬停展开；“全部展开”和应用 FIX 仅在左右侧栏使用。切换方向会保留已有固定状态。

官网新增四方向互动演示，默认展示顶部三行卡片、四窗口续卡、Focus 预留和横向滚动。演示使用网页内虚构窗口，不读取访客桌面。

## 验证范围与限制

- 本机 Release 编译零警告、零错误；94 组回归通过。几何回归覆盖横屏／竖屏、100%／125%／150%／200% DPI、多窗口分格、续卡、精确点击、截图比例、边缘滚动与方向切换。
- 独立原生预览已核对顶部／底部箭头和标题样式。官网演示另外核对横向布局、窗口选择、Focus、全屏唤出、语言切换及窄屏展示。
- 上述自动测试不等同于所有真实显示器热插拔、全屏应用及连续 24 小时稳定性验收；这些完整人工场景尚未全部完成。本次根据维护者的明确发布请求，在 CI 通过并验证正式资产后公开发布，不将其标记为已完成长期稳定性验收。
- Antigravity 读取依赖本机已登录客户端的可用状态及未公开协议，服务更新可能影响兼容性。Gemini 网页订阅桥接的真实账户兼容性仍不能保证；失败时显示未连接／更新失败，不用 API 余额代替订阅额度。
- 保留历史 Release 供回退；此前本机程序及设置备份不删除。

## English highlights

Dock on any of four edges. Top and bottom now use stable cards with up to three directly clickable window rows, continuation cards, grouped shortcuts and desktop controls. Full-aspect portrait previews, gentle 4° perspective, transparent captions and edge scrolling complete the new layout. Side docks retain expansion and independent FIX controls. This release also includes local Antigravity usage integration and hover/capture lifecycle fixes.

CI-built, self-contained Windows x64 EXE with SHA-256, build manifest and artifact attestation. Comprehensive real-monitor and 24-hour stability acceptance remains incomplete; it is not claimed as passed.
