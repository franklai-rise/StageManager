# Stage_Manager_Lai v4.8.2 · 自选显示器与设置体验升级

## 新增：选择卡片栏所在屏幕

打开 **设置 → 工作区 → 显示器**：

- **自动 · 最左侧屏幕**：延续旧版本默认行为。
- **Windows 主显示器**：跟随系统主屏。
- **指定显示器**：列表展示当前连接的屏幕、名称、分辨率及主屏标记。保存后生效，上下左右四边均可使用。

优先使用 Windows 提供的显示器设备标识记住选择，避免只靠 DISPLAY 编号串屏。指定屏幕断开时临时使用主屏，不覆盖保存的选择；重新检测到相同屏幕后自动返回。切换屏幕先释放旧屏的 Focus 预留区域，不改变各应用原有窗口位置。更换显卡接口、驱动或特殊扩展坞可能改变设备标识，届时需重新选择。

## 一并发布此前本机版本的改进

- 设置页紧凑排版、清晰字体、模块导航及主题选项；输入框、按钮、开关和模块空白处均可滚动整页，不再误改数值；展开的下拉菜单保留独立滚动。
- 修正隐藏配置区仍占高度造成的大空白。
- AI 额度刷新间隔可设 **30–3600 秒**，默认仍为 300 秒；修复计时误差跳过一整轮刷新。
- Codex CLI 自动查找、路径说明和连接测试；优先查找兼容的本机版本目录，旧 CLI 退出时给出可操作提示。
- 可选 Outlook 日历卡片（默认关闭）：日期卡、月历和日程详情、本机完成勾选，采用与 AI 面板一致的深色透明风格。
- 日历支持通过已连接的 Codex Outlook 插件**手动刷新**。需要可用的 Codex CLI 及相应插件连接，不启动模型回复。微软直连模式仍需自行注册公开桌面客户端 ID。
- 保留 OPEN/FIX、多窗口独立固定、Focus 和四边布局的现有操作。

## 隐私与兼容

- 不新增遥测，不内置账号、密钥、登录令牌或私人日程；日历与 AI 卡片默认关闭。
- 日历缓存、令牌和 API 密钥按现有规则由当前 Windows 用户加密保护；完成勾选仅存本机，不修改 Outlook。
- 设置升级至 schema 23，迁移前保留备份；旧用户默认继续使用最左屏，不改变卡片大小、停靠边或账号开关。
- Windows 10 2004+ / Windows 11，x64，自包含单文件 EXE。保留原作者 Andreas Wäscher 的署名与项目许可证；这是 Frank Lai 的修改版。

## 验证范围及本次发布说明

v4.8.1 的 CI 发现旧日历测试错误地假定模拟显示器尺寸能超过云端 Windows 的原生窗口尺寸上限。v4.8.2 按 .NET WinForms 的 MaxWindowTrackSize 规则修正该断言，仍验证准确 DPI 尺寸、工作区边界及受限空间内的滚动；没有跳过该测试，也没有覆盖旧标签。

本次由维护者要求直接发布，不替换其本机程序、桌面快捷方式或开机启动入口。CI 构建的同一 EXE 提供 SHA-256、build-info.json 和 GitHub 构建证明。

自动回归覆盖显示器选择、拔插回退模拟、编号变化、选择持久化、设置迁移和中英文界面，以及现有卡片、截图隔离、Focus、日历和 AI 功能。**物理显示器热拔插/扩展坞、多机混合 DPI 手工验收及本次新 EXE 的 24 小时长期运行尚未完成**，不以旧版本运行时长代替。日历跨账号、CLI 版本与各平台真实额度仍以各用户实际连接情况为准。

源码与 EXE 均以本标签和 build-info.json 指向的 CI 提交为准。SHA-256 用于核验下载完整性，不等同 Windows 代码签名。
