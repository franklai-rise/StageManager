# Stage_Manager_Lai v4.7.1 — 四边缘滚动与一页式设置

本机试用版，未推送或发布 GitHub Release。

## 左右侧栏

- 鼠标进入侧栏内上、下各约 80 DIP 的区域即开始缓慢滚动，随靠近边缘以平滑曲线逐渐加速，最高 480 DIP/秒；不监听整块桌面的上下边缘。顶部／底部横栏仍使用原来的 24 DIP。
- 离开区域、隐藏侧栏、按下鼠标、打开菜单／AI 详情时停止；滚轮优先，沿用 250 毫秒抑制时间。
- 只移动有真实溢出的内容，不使用滚轮的额外回弹范围。空白边缘仍可穿透点击，不创建额外窗口或鼠标钩子。
- 悬停在多窗口主卡、FIX 或 AI 卡上时让位给交互。保留按应用分组、主卡到子卡的延伸连接线、独立 FIXED 状态和原有展开方式。
- 顶部、底部的边缘滚动和三行组合卡保持原状。

## 一页式设置

- 工作区、偏好设置、卡片与快捷启动、窗口与预览、键盘快捷键、更新与关于、AI 额度全部直接展开，不再切换分类页。
- 连续纵向滚动；模块编号、说明、圆角细边框、大开关和清晰文字区分层级。保存／取消始终在底部。
- 右上角可输入设置名称，按回车跳到对应位置，不隐藏其他模块。
- 中英文、浅色／深色／跟随系统、大号字体、记忆上次模块、自动检查更新均保留。
- 使用本机已有的 Noto Sans SC（如可用），否则使用 Microsoft YaHei UI；不安装或打包字体，不引入浏览器运行库。
- 沿用 schema 21 与原有所有设置和密钥保存逻辑，本次不重置任何用户偏好。
