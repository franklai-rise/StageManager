# Stage_Manager_Lai v4.7.2 — OPEN 与彩色设置导航

本机试用版；本次没有推送 GitHub、发布 Release 或修改网站。

## 应用组操作与留白

- 左右侧栏的多窗口应用主卡展开后，FIX 下方新增 OPEN。一次恢复并依序置前该应用全部窗口，包含分页之外的窗口；不切换为最小化、不重排子卡，也不取消 FIXED。
- 保留各窗口的现有位置、最大化状态和原有 Focus 处理。重叠窗口仍按层叠关系显示，不自动平铺。
- OPEN 采用与主卡一致的透视角，独立悬停、按下和处理中反馈。按下后在同一按钮释放才执行；处理中重复点击不会排队。
- 操作可取消；关闭/失效窗口跳过，单个失败不阻塞后续窗口。Windows 拒绝前台激活时保留原有提示和任务栏闪烁策略，不强制抢焦点。
- 折叠组按前后全部卡片的投影轮廓排版，相邻应用组间距为 14 DIP。展开的主卡和上方卡片位置保持不变，后续卡片向下排列。
- 顶部／底部三行模式保持原有布局，没有加入 FIX/OPEN 覆盖按钮。

## 设置导航

- 左侧固定约 108 DIP 的窄导航区域，七个彩色按钮对应工作区、偏好、卡片、窗口、快捷键、更新和 AI 额度。
- 点击后约 220 毫秒平滑滚到模块；所有模块继续在同一页展开，不切换分类页面。
- 导航颜色对应模块标题；手动滚动更新当前模块，滚轮/滚动条和新导航可打断旧动画。关闭动画或系统减少动画时直接定位。
- 矮窗口下导航自身可滚动；保留搜索定位、中英文、主题、字号及底部保存栏。不增加持久化设置或修改用户偏好。
