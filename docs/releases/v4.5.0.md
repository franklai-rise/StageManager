# Stage_Manager_Lai v4.5.0

## Changes / 更新

- Isolated mouse-wheel hook thread with nonblocking UI delivery and expiring hit regions.
- Isolated screenshot worker with two-second capture timeout and bounded recycling.
- Permission-aware window badges and verified activation/minimize outcomes.
- Select and order application launcher cards in Settings, including Start menu shortcuts.
- GitHub Issues enabled; main is the canonical production branch.
- CI-built single-file Windows x64 EXE, SHA-256, source commit manifest and artifact attestation.

Existing Focus, FIX/FIXED, tray cards, desktop controls and window placement behavior are retained.

## Validation gate / 验证门槛

This release is created as a **draft**. Public promotion requires a completed
24-hour local Windows validation record using these exact executable bytes.
Do not replace this EXE with a locally rebuilt copy.

## Verify / 核验

Compare SHA256SUMS.txt with Get-FileHash. With GitHub CLI:

```powershell
gh attestation verify Stage_Manager_Lai_v4.5.0.exe --repo franklai-rise/StageManager
```

Attestation links this EXE to a CI build and source commit; it is not Authenticode
signing and does not retrospectively attest v4.4.16.
