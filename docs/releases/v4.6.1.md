# Stage_Manager_Lai v4.6.1

## 更新内容
- AI 额度卡片改为两行两列：Codex / DeepSeek、Gemini / Kimi。
- Codex 图标改为黑白，Gemini 加入可缩放星形标识。
- 新增实验性 Gemini 网页订阅额度桥接：当前/每周额度、重置时间、过期/未连接状态。不是 API 余额。
- 修正四格布局的点击平台定位，详情页增加 Gemini 页签。
- 保留 AI 总开关默认关闭和原有平台选择；未启用平台保留格位，不发起查询。

## 下载与安装
- 普通用户：下载 `Stage_Manager_Lai_v4.6.1.exe`，自包含 Windows x64 单文件。
- 需要 Gemini：另外下载 `Stage_Manager_Lai_Gemini_Companion_v4.6.1.zip`，解压后按 `INSTALL.txt` 注册本机助手并在 Chrome/Edge 手动加载扩展。
- 不需要分享账号密码、Cookie 或 API Key；Google 登录会话不离开浏览器。
- 核对 `SHA256SUMS.txt`；EXE 与配套 ZIP 均由本标签 CI 构建并提供 GitHub 构建证明。SHA-256 不等同代码签名。

## 验证范围 / 已知限制
- 自动测试覆盖额度解析、边界值、缓存过期、退出登录状态、消息 framing、来源及未知命令拒绝。
- Gemini 真实账号端到端读取尚未验证。接口未公开，可能因服务变化、地区或账号权限不可用；不能承诺所有 Pro 账号可读。
- 使用浏览器默认 Google 账号；切换账号需重新连接。请只启用一个浏览器配置文件。
- 浏览器关闭后不能保证持续更新；StageManager 每五分钟读取缓存，手动刷新读取本机缓存，主动网络刷新请使用浏览器扩展按钮。
- 配套扩展/助手独立安装，不随主程序一键更新自动安装。
- 用户已明确批准本次豁免 24 小时验收，在 CI 通过后发布。长期稳定性及手动完整回归未完成；后续版本仍保留原验收门槛。
