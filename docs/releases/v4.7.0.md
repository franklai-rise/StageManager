# Stage_Manager_Lai v4.7.0 — Settings & preferences

Local trial build; not yet published to GitHub.

## 设置界面

- 七个分类：常用设置、卡片与快捷启动、AI 额度、窗口与预览、键盘快捷键、偏好设置、更新与关于。
- 常用页快速进入应用快捷启动、偏好和更新；保存／取消始终固定在底部。
- 原生 DPI 感知控件、清晰的文本绘制、44 DIP 操作按钮、46 DIP 导航按钮、更宽松的行距。
- 可自由缩放；窄屏时分类导航转为顶部选择框。长内容仅在当前分类内纵向滚动。
- 深色、浅色、跟随系统主题，标准／大号文字，记忆上次设置分类，可关闭升级后的介绍窗口。
- 主题和文字大小可即时预览；保存后应用到下次打开，取消不提交修改。保留全部现有卡片、快捷启动、AI 和窗口控制设置。

## 自动检查更新

- 默认启用，可在“更新与关于”关闭。
- 启动约 45 秒后检查官方 GitHub 正式版；持久化检查时间，此后自动检查间隔至少 24 小时。
- 请求异步执行、15 秒超时；关闭开关或退出程序取消请求。同一版本只通知一次，检测到全屏或设置窗口打开时延后提示。
- 仅查询版本信息，不自动下载或安装，不发送登录凭据。手动更新和现有文件校验、回退流程继续保留。
- 断网、限流和异常响应保持安静，不能误报“已是最新版”。

## 兼容与恢复

- 设置 schema 20 → 21，迁移前保留备份。原有 Focus、停靠方向、AI 开关、快捷方式和密钥不被重置。
- 更新检查记录独立存储在 automatic-update-state.json，不包含账户或窗口数据。
- 单文件 EXE 放在项目 Releases；本机稳定入口仍为 Releases/Current/Stage_Manager_Lai.exe。

自动检查使用可控时钟和模拟响应验证启动延迟、每日频率、取消、通知去重和全屏延后；不是等待真实 24 小时。
