# v4.7.3 本机验证

日期：2026-10-23；本机试用交付，不等于正式 Release 或长期验收。

## 原因与修改

- 原指针控制器直接输出瞬时速度，没有时间平滑；横向热区内边界还有 100 DIP/秒的突变。
- 原边缘滚动每帧重新命中卡片，将滚到静止指针下方的多窗口主卡/FIX 等误认为用户新悬停，从而停止滑动。
- 原接管函数直接钳位位置，在滚轮额外位移范围里可能跳回真实内容边界。
- 修正分别为平滑速度/积分、滚动会话的指针意图判定、保持当前位置的向内接管。滚动期间不弹出经过的 AI 卡详情或目标提示。

## 自动化

- Release 编译：0 警告、0 错误。完整 98 组回归通过。
- 平滑器测试：75%–200% 缩放下起步、单调加速、换向不反拖、立即停止、长帧不追赶、30/60/120/144 Hz 与不规则帧间隔的距离一致性、末端制动和不越界。
- 指针意图测试：两轴、双方向、多 DPI；初次悬停控件优先、移动卡片经过不打断、向内或横向主动移入控件时让位、隐藏/菜单状态重置。
- 真正 Composition 渲染器测试：左右布局中模拟主卡滑到静止指针下方，验证继续滚动；主动向内移入主卡则停止。其余滚动命中、独立 FIX、OPEN、Focus、AI 与设置测试全部通过。
- 原有滚轮范围/弹性不变；新增接管测试确保超出真实内容范围时不会瞬间跳回。
