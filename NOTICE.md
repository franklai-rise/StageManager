## Lai modification scope

The v1 series added fixed leftmost-monitor placement, simultaneous multi-window use, Windows shell and Yuanbao
protection, desktop-icon preservation, hook cleanup, compact cards, and adaptive sizing.

The v2 series adds runtime multi-application stages, Coexist and Focus modes, multi-display layout restoration,
composite live previews, settings and hotkeys, virtual-desktop awareness, full-screen suppression, safe startup,
serialized window events, transient-window filtering, UWP process resolution, and automated regression tests.
