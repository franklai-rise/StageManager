04 / 你可能想知道

还有几个小问题。

反馈问题 ↗
它与原版 StageManager 是什么关系？

这是 Frank Lai 在 Andreas Wäscher 原项目基础上持续维护的修改版。保留原作者署名与 MIT 许可，网站底部提供原项目链接。

需要什么系统？需要安装吗？

Windows 10 版本 2004 或更新的 x64 系统。下载的是自包含单文件 EXE，可直接运行。当前版本未进行发布者代码签名，请从这里链接的官方 GitHub Release 下载。

普通模式与 Focus 有什么区别？

普通模式适合自由摆放窗口；Focus 会为左侧卡片栏保留工作区。真正全屏的应用可以覆盖侧栏区域，靠近左缘仍可唤出。你可以在上方演示中直接比较。

卡片会一直截图吗？

默认使用静态窗口预览。刷新间隔可在设置中调整为 1–60 分钟，隐藏侧栏时也可以暂停刷新。

被忽略的应用，怎么添加回来？

从系统托盘打开设置，在忽略应用列表里取消勾选。忽略只影响侧栏卡片，应用仍可正常打开。

网页演示会访问我的桌面吗？

不会。演示中的窗口和内容都是网页内的虚构示例，用来体验主要交互；实际软件的外观与功能以下载版本为准。
